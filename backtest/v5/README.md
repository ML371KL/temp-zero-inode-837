# Бэктест-стенд v5.0

Python-реплика движка панели (docs/index.html) на исторических данных 2000–2026 и все прогоны,
на которых приняты решения v5.0: лестница 100/50/0, правила исполнения, калибровки карточек, модель
риска просадки. Базовая реплика (`engine.py`, `loader.py`, `harness.py`) — из аудита сентября-2026
(ветка `data`, backtest/audit-2026-09); `eng5.py` добавляет поверх неё логику v4.15.1 (VIX по
изменению, иена без уровней, нефть с индексацией) и переключатели кандидатных правок v5.0.

## Данные (в репозиторий не входят)

```
cd backtest/v5
bash fetch.sh && bash fetch2.sh          # FRED (fredgraph.csv) и Yahoo (кусками по 5 лет) → data/
git clone --depth 1 https://github.com/viki-m13/bonds /tmp/bonds && mkdir -p mirror && \
  cp /tmp/bonds/data/fred/{BAMLH0A0HYM2,BAMLC0A0CM}.csv mirror/
```

FRED сейчас отдаёт ряды ICE BofA (HY/IG OAS, CCC, BB) только за последние 3 года, поэтому полная история
HY/IG с 2000 года берётся из публичного зеркала. Истории CCC/BB за пределами 3 лет нет — поэтому карточка
расслоения кредита в панели справочная.

## Прогоны (PYTHONIOENCODING=utf-8 python3 <скрипт>)

| скрипт | что проверяет |
|---|---|
| b0_base.py | воспроизведение аудита (Sharpe 0,76 / −18,2% / 9,29%) и живой v4.15.1 |
| b1_flags.py | каждая кандидатная правка по отдельности, среднее по окрестности порогов |
| b2_combo.py | комбинации принятых правок |
| b3_thr.py | сетка порогов лестницы 100/50/0, гейт, гистерезис, проверка «обучись на половине» |
| b4_final.py | итоговая конфигурация против индекса, прежней лестницы и простых правил |
| b5_dotcom.py, b6_dotcom_grid.py, b7_t2.py | медвежий рынок 2000–2002 и чувствительность нижнего порога |
| b8_tail.py | модель риска падения на 10%+ за 3 месяца (логит, проверка вне выборки) |
| b9_regimes.py | базовые частоты и исходы по режимам риска |

Флаги `eng5.build(flags=...)`: OIL — нефть относительно средней за год; TGD — TGA вне балла; POL —
путь ФРС (2-летка минус ставка); SOF — SOFR−IORB по среднему за 3 дня; прочие (IGF, IGP, NFR, NFQ, CRV,
TGW, HMF, LDW, RGC, HAWK, RRL, HYZ, SPZ) — проверенные и отвергнутые альтернативы.
